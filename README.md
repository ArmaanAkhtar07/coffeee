# Craft Coffee Website

A premium coffee shop website featuring scroll-driven canvas animations, glassmorphism design, and a modern aesthetic.

## Features
- **Smooth Scroll Animations**: High-performance canvas-based frame rendering.
- **Glassmorphism UI**: Modern, transparent interface with subtle blur effects.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **Vercel Ready**: Pre-configured for easy deployment on Vercel.

## Deployment
This project is ready for deployment on [Vercel](https://vercel.com).
Simply push to GitHub and connect your repository to Vercel.

## Local Development
Since this project uses static HTML/CSS/JS, you can simply open `index.html` in your browser.
To serve with a local server:
```bash
npx serve .
```
